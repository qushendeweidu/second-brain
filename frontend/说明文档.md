# 大众商城（DAZHONG MALL）前端 说明文档

> 依据：`前端需求文档.md` v1.2；技术规范：dev-design/web-frontend skill（管理端 ElementPlus，用户端 Radix Vue + Tailwind + Iconify）。
> 说明：产品为"大众商城"电商平台；`second-brain` 只是后端工程名。

## 一、项目规划

| 模块 | 端 | 页面 | 接口 |
|---|---|---|---|
| 认证 | 用户端 | `/login`、`/register` | `/user/login`、`/user/register`、`/user/get_short_token` |
| 个人中心 | 用户端 | `/me` | `/user/profile/myself`、`/user/updateUserProfile`、`/user/saveUserAvatar` |
| GitHub 绑定 | 用户端 | `/me`、`/oauth/github/callback` | `/auth/github/authorize`、`/callback`、`/unbind` |
| 用户管理 | 管理端 | `/admin/users` | `/user/list`、`/user/{id}`、`/user/create`、`/user/update`、`DELETE /user/{id}` |
| 角色权限 | 管理端 | 用户列表内弹窗 | `/user/role/{userId}`、`PATCH /user/role`、`DELETE /user/role/{userId}` |
| 账户管控 | 管理端 | 用户列表内弹窗 | `/user/blockedUser`、`/user/deleteUserSecurity/{id}`、`/user/restrictUserToken` |
| 商城业务（规划中） | 用户端 | 待定 | 后端暂无商品/购物车/订单接口，本期不做 |

## 二、实施方案

- 技术栈：Vue 3.5 + Vite 7 + TypeScript 5.9 + Pinia 3 + Vue Router 4 + Axios + dayjs。
- 开发地址 `http://127.0.0.1:5173`（与后端 `CALLBACK_ADDRESS` 一致）；`/api` 代理到 `http://localhost:8808`，去掉前缀并移除 `Origin` 头。
- 双 token：`utils/token.ts` 存取；长 token `localStorage`，短 token `sessionStorage`；短 token 过期前自动用 `get_short_token` 换取；解码结果按 token 缓存。
- 响应拦截：以 `body.code` 判断；`401/40101/40102` 清 token 跳登录；40103/40104 提示无权限。
- 权限：解析短 token（`AccessToken`）payload 得 `roles/permissions`；路由守卫校验 `ADMIN`；`v-permission` 指令做按钮级控制。
- `updateUserProfile` 与 `restrictUserToken` 均按 JSON body 提交（后端已补 `@RequestBody`）；头像 `multipartFile` 字段 + `?userId=`；头像对象名自动补 `/file/` 前缀。
- 品牌：Logo `src/assets/logo.png`（由根目录 `dazhong_mall_logo_high_quality.webp` 转出），favicon `public/favicon.png`；主色钴蓝 `#0C50C0`，点缀红 `#C8283A`。

## 四、已知限制

- 后端无"查询本人 GitHub 绑定状态"接口，个人中心同时提供"绑定/解绑"操作。
- 后端无"查询本人角色"接口，角色取自短 token（`AccessToken`）claim；冷启动只有长 token 时由路由守卫先换短 token；角色变更后需重登才生效（后端会强制下线）。
- 后端无商品类接口，前端暂无商品首页、购物车、订单页面。
